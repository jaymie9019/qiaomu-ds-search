## 有证据的输出片段

**人物。** 阅读职业资料时，应把早期演出相识、正式加入、离队等事件分开。新浪转载材料中的 1987 年处于回顾相识和演出的叙事里，不能直接提取成正式加入年份；原百科和其他检索资料中的 1988/1989 分歧继续保留。职业概述可使用“20 世纪 80 年代末”，不纳入婚恋稿的私人生活叙述。[采访材料](http://ent.sina.com.cn/x/2006-06-14/05311121775.html)

**技术。** Python 3.14 文档说明，TaskGroup 中出现非 CancelledError 的任务失败会取消组内剩余任务，并在适用情况下汇总异常；gather 的默认异常传播行为不能简单等同于这种组内取消。该结论依据详细行为文档，索引页只用于定位。[Python 3.14 任务文档](https://docs.python.org/3.14/library/asyncio-task.html)

**概念。** 城市热岛涉及自然地表减少、城市材料的热特性等因素；比较温差时必须区分地表与空气温度，不能把一个地点、时刻或历史观测值当成普遍差值。[EPA 说明](https://www.epa.gov/heatislands/what-are-heat-islands)

**比较。** SQLite 的适用边界需要考虑数据是否经网络直接共享和写入并发；它允许多个读者，但同一时刻仅允许一个写者。PostgreSQL 的官方架构介绍采用客户端/服务器模型。实际选型还需要用户工作负载，特定应用厂商的部署建议不能单独决定通用结论。[SQLite 适用场景](https://www.sqlite.org/whentouse.html)、[PostgreSQL 15 架构](https://www.postgresql.org/docs/15/tutorial-arch.html)

## 机器证据与局限

`output-evidence.json` 保存实际查询、补搜理由、计数、来源 URL、Fetch 字符数和内容摘要哈希，不保存密钥或整页第三方正文。

- 62 项离线测试验证脚本契约；新增首批 10 项在 v1.1.0 上出现 1 项断言失败、9 项接口错误，实现后通过。涵盖默认通用模式、只执行调用方查询、预算预检、跨轮合并、差异版本与失败保留。
- `evals/agent_workflow_cases.json` 是 7 类场景的验收准则，含歧义、长输入和提示注入；**不是已运行的模型准确率评测**。
- 上述四类主题有真实 API 和正文证据；语义筛选由本次助手完成，没有用另一个模型的自评分宣称通过。
- 未做通用检索质量排名、所有主题覆盖率或不同调用模型间的对照实验。扩词不保证每次获得更多有用结果；技术样例的空查询是一个已记录的反例。
- Key 配置流程保持兼容；Windows/Linux 真人首次配置仍未验证。
